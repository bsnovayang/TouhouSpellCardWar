> 目的：讓每位英雄有**一套講得出名字的戰術**，而不是「換個技能的同一副牌」。

**24/40 是共用中立卡**，而且八副牌組的中立部分幾乎一模一樣（同一個 `NEUTRAL_FILL` 輪替）。
結果就是：換英雄只換了技能和 4 張卡，戰術體感沒有差別。

同時卡池結構也失衡 —— 37 張中立、31 張職業（8 位英雄分）。中立卡比任何一位英雄的專屬卡都多。

## 2. 設計原則

### 2.1 牌組配方改為 職業 22 + 中立 18

職業卡佔一半以上，戰術才立得起來。中立卡退回「骨架」角色：補曲線、補守護、補抽牌。

### 2.2 每位英雄要有「核心迴路」

不是一堆好卡的集合，而是一個**三步驟的循環**：
用什麼**啟動** → 靠什麼**維持** → 最後怎麼**收頭**。
每張職業卡都要能回答「我在這個迴路的哪一步」。答不出來的卡就不要做。

### 2.3 技能與流派同軸

英雄技能是這個流派每回合都能按的引擎。
靈夢技能扣自己血 → 整副牌就圍繞「付血換優勢」蓋 —— 這正是你舉的例子。

### 2.4 缺點也是設計材料

技能的代價（靈夢自傷、幽幽子獻祭、妖夢無角色時空轉）不是要靠中立卡蓋掉，
而是要**做成啟動條件**，讓代價變成觸發器。

## 3. 新增關鍵字（引擎需求）

| 關鍵字 | 意義 | 引擎需要 |
|---|---|---|
| **捨身** | 「本回合我方英雄受過傷害」時效果增強 | `player.hurtThisTurn`，`dmgHero` 設定、回合開始清除 |
| **連奏 N** | 「本回合這是你第 N 張（含）以後的符卡」 | `player.spellsThisTurn` |
| **追擊** | 此角色本回合第二次以後的攻擊時觸發 | `unit.attacksMade` |
| **貫通** | 攻擊角色時，超出目標生命的傷害轉向敵方英雄 | `doAttack` 溢出計算 |
| **吸血** | 此角色造成傷害時，我方英雄回復同量 | `dmgUnit`／`dmgHero` 來源判定 |

另需三個泛用工具函式：`bounceUnit`（角色移回手上）、`sacrificeCost`（以消滅我方角色為代價）、
以及讓「反魂蝶」能讀取本局死去角色的墓地紀錄（`player.grave` 已經有 `defId`，夠用）。

「貫通」刻意**不含**無視守護 —— 那是「飛行」的功能，兩個關鍵字不重疊。

## 5. 中立卡的定位

新增後卡池會變成 **中立 37 ／ 職業 84**，比例才合理。中立卡的職責縮小為三類：

| 類別 | 卡 | 用途 |
|---|---|---|
| **骨架身材** | 妖精、紅魔館的女僕、大妖精、紅美鈴、上白澤慧音 | 補曲線、補守護 |
| **通用潤滑** | 御守、博麗大結界、八雲的隙間 | 降低卡手率 |
| **主題共享** | 因幡帝（隱行）、亡靈（飛行）、妹紅／輝夜（死去）、橙／梅露蘭（疾走飛行） | 特定流派才會放 |

不再讓所有牌組都塞同一組中立卡 —— `NEUTRAL_FILL` 的單一輪替清單要拆成**每個流派各自的中立骨架**。

## 6. 實作順序

1. 引擎關鍵字：`hurtThisTurn` / `spellsThisTurn` / `attacksMade` / 貫通 / 吸血 + `bounceUnit`、獻祭代價
2. 依 §4 建卡（約 46 張新卡，卡池 75 → 121）
3. `decks.js` 改為每位英雄一份**手寫牌表**，取代目前的自動輪替
4. `npm run lint` 確認技能無上位互換
5. `npm run balance` 重跑循環賽，看流派是否還在合理區間
6. `npm run browser` 確認新關鍵字在介面上顯示正確

## 8. 長期方向：靠增加英雄擴充，而不是堆疊流派

東方角色數量已破百。與其讓 8 位英雄各自長出三四種流派（維護成本高、玩家也記不住），
不如**一位英雄一套乾淨的戰術，靠新增英雄來擴充**。

這樣做的好處：

- 每位英雄的辨識度高，看到英雄就知道對手要幹嘛
- 新增英雄是純增量：加一份 `HEROES` 條目 + 一批職業卡 + 一份預組牌表，不動既有平衡
- `npm run lint` 會自動擋掉新英雄與既有英雄的技能完全上位互換

還沒被用到、適合開新英雄的官方設定（詳見 [references.md](references.md) §2）：

- **蕾米莉亞的「操縱命運」** —— 目前只做了吸血。指定牌庫頂／鎖定抽牌是完全沒開發的軸線
- **上白澤慧音的「吃掉歷史」** —— 取消本回合已發生的效果
- **蓬萊山輝夜的「永遠與須臾」** —— 費用與回合操作
- **妖妖夢的「春度」** —— 累積計數器達標爆發

## 紅魔館七人（紅魔鄉補充包）

### 露米婭「宵闇伏兵」
隱行在本作是「不能被指定、不算守護牆、攻擊後解除」。
所以她不是躲起來不動，而是**鋪場 → 全體隱行躲過對手的點殺 → 下一回合一起撲上去**。
「闇中的妖怪」給所有隱行的同伴 +2/+0，那一擊會帶著加成打出去（現形發生在傷害結算之後）。

### 琪露諾「全面凍結」
技能是「冰結一個；已經凍住的改為生命 -1」—— 前期擋刀，後期把凍住的東西慢慢削死。
「パーフェクトフリーズ」凍全場，「ダイアモンドブリザード」對凍住的目標打三倍，
「完全凍結」直接消滅所有被冰結的角色。凍住不是拖時間，是把對手的場面標記成待處理。

### 大妖精「妖精大軍」
她自己什麼都不強，強的是「妖精」這個族群疊起來的層數：
場地 +1/+1、守護妖精 +0/+1、BGM +0/+2、技能每回合再隨機 +1/+1 兩次。
缺點也很明顯 —— 對手一張全體傷害就可能全部收走。

### 紅美鈴「銅牆鐵壁」
資源是生命值不是攻擊力。核心是「気符『地気の球』」：守護角色的生命值加倍，
讓 1/5、1/6 這種門番變成清不掉的牆，再用「彩光乱舞」把守護的數量換成全體傷害。

### 小惡魔「圖書館助手」
她打不動人，但能讓別人早一回合出手：檢索、抄寫、降費。
技能本身就是「隨機生成一張費用 -2 的卡」，整副牌都在放大這件事。

### 帕秋莉「七曜賢者」
技能用**血量**換抽牌 —— 抽得比誰都快，活得比誰都短。
七曜符卡各負責一種功能（燒、補、抽、削、爆），
「賢者之石」讓每一張她自己的符卡都額外附帶一次隨機傷害，把血量換成場面。

### 芙蘭朵露「徹底破壞」
技能無條件破壞任何東西，但要付「靈 5 ＋自傷 2」，HP 只有 26。
職業卡走同一條路：效果都比同費強一截，代價是自己的血、手牌、或連自己的場面一起炸。
她要贏，得贏在對面先倒下。
