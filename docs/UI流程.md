# 介面流程設計

> 針對「英雄會從 8 位長到 28 位」所做的介面調整與後續規劃。

---

## 1. 問題

英雄下拉選單**本來就會自動長出來**（從 `HERO_ORDER` 動態產生），所以加英雄不會漏掉。
但 `<select>` 在 28 個項目時是很糟的體驗：

- 看不到技能、血量、流派 —— 選角最需要的資訊全都藏起來
- 無法比較，只能一個一個點開看
- 要捲動，而且捲到一半會忘記前面看過什麼

**選英雄是決定整副牌組走向的動作，卻用了資訊量最少的元件。**

---

## 2. 新流程

```
牌組編輯
   └─ ＋新牌組 ──→ 【英雄選擇】──→ 牌組編輯器
                      分作品分頁          頂部有英雄橫幅
                      可搜尋               「更換英雄」可回到選擇畫面
```

### 英雄選擇畫面

一位英雄一張卡，直接把選角需要的東西攤開：

```
┌──────────────────────────────┐
│ (頭像) 八雲紫              26 │  ← 血量
│        境界的妖怪             │
│ 「境界操作」                  │  ← 流派名
│ ┌──────────────────────────┐ │
│ │ 境界操作（2）             │ │  ← 技能名與費用
│ │ 交換一個角色的攻擊力與生命 │ │  ← 技能說明（關鍵字會標成 TAG）
│ └──────────────────────────┘ │
│ 職業卡 10 種                  │  ← 這位英雄有多少專屬卡
└──────────────────────────────┘
```

- **分頁**：全部／東方紅魔鄉／東方妖妖夢／東方永夜抄，數量即時顯示
- **搜尋**：比對名字、稱號、技能名、技能說明、流派名
  （搜「冰結」會同時找到琪露諾與蕾迪 —— 因為兩人技能說明都有這個關鍵字）
- 「全部」分頁會依作品分段顯示，不會變成一坨

### 牌組編輯器

下拉選單改成**英雄橫幅**，永遠看得到自己在為誰組牌：

```
┌────────────────────────────────────────────┐
│ (頭像) 八雲紫「境界操作」          [更換英雄] │
│        境界操作（2）交換一個角色的攻擊力與生命 │
└────────────────────────────────────────────┘
```

**更換英雄會先算損失再確認**：

```
換成「愛麗絲·瑪格特羅依德」會移除 5 張職業卡。確定嗎？
```

按取消就完全不動；確認後只會濾掉不合法的職業卡與 BGM，中立卡全部保留。

### 新牌組的預設值

選完英雄後自動帶入：

- 牌組名稱＝「八雲紫・境界操作的牌組」（可改）
- BGM 欄＝該英雄的預設主題曲

省掉「建立空白牌組 → 自己去挑 BGM」這兩步。

### 預設牌組的作品分頁

預設牌組與英雄數 **1:1 成長**（28 位英雄＝28 副預設牌組），所以兩個會列出預設牌組的地方
—— **對戰選擇畫面**與**牌組編輯的預設清單** —— 都加了作品分頁，共用同一套 `renderSetTabs()`。

牌組卡片也把 BGM 獨立成一行（金色），沒設定時顯示灰色的「未設定 BGM」，
不會跟 ⚠ 錯誤訊息擠在一起看不懂。

## 3. 設計取捨

| 決定 | 理由 |
|---|---|
| 用**卡片牆**而不是清單 | 技能說明是多行文字，清單塞不下；卡片牆能同時比較 6~9 位 |
| 分頁用**補充包**而不是族群／流派 | 玩家的心智模型是「我想玩妖妖夢的角色」，不是「我想玩亡靈系」 |
| 搜尋比對**技能說明**而不只是名字 | 玩家常常是「我想要能冰結的英雄」而不是「我要找琪露諾」 |
| 卡片上顯示**職業卡種數** | 直接反映這位英雄的內容量，新包的英雄一眼看得出比較單薄 |
| 更換英雄**先算損失** | 這是破壞性操作，不能默默刪掉 5 張卡 |

## 4. 隨規模成長還需要處理的

以下目前還撐得住，但卡池到 400 張、英雄到 28 位之後會變成問題：

| 項目 | 現況 | 屆時要做 |
|---|---|---|
| ~~編輯器的卡池~~ | ✅ 已改成可複選的按鈕群：費用 0~7+、種類、族群、收錄作品 | — |
| **我的牌組列表** | 平舖 | 加排序（最近編輯／英雄／作品）與搜尋 |
| **牌組列表資訊** | 只有英雄＋張數＋BGM | 加上費用曲線縮圖，一眼看出快攻／控制 |
| **英雄卡的頭像** | 名字第一個字＋色塊 | 有美術資源時換成立繪 |
| **對戰中的英雄技能** | 文字按鈕 | 英雄多了之後可考慮圖示化 |

**已經驗證過 28 位英雄的情況**：分頁正確分成 11／9／8，搜尋正常，版面沒有破。

## 5. 卡池篩選

原本費用是寫死的區間下拉（0-1／2-3／4-5／6+），玩家沒辦法只看 3 費。
改成**可複選的按鈕群**：

```
費用  [0][1][2][3][4][5][6][7+]        ← 可以同時選 2 和 3
種類  [角色][符卡][結界][場地][BGM]
歸屬  [專屬（10）][中立（58）]           ← 數量即時顯示
      ─── 更多篩選 ▾ ───
族群  [人類][妖精][妖怪][亡靈][騷靈][魔法使][人偶][吸血鬼][式神][月人][惡魔][妖獸]
收錄  [紅魔鄉][妖妖夢][永夜抄][不屬於任何作品]
```

- **什麼都沒選＝不限制**，不需要「全部」這個選項
- 同一列複選是 OR（費用 2 或 3），不同列之間是 AND
- 右上角即時顯示「41 / 68 張（2 個條件）」，一眼知道篩掉多少
- 族群與收錄作品收在「更多篩選」裡，預設收合避免佔版面
- 「收錄」篩選是為了**作品結界**那套組牌取捨 —— 要挑能吃到多種結界的角色時，這是唯一的入口

### 專屬卡的視覺區分

卡池同時列出「中立卡」與「這位英雄的專屬卡」，但兩者原本長得一模一樣 ——
靈夢的 68 張卡池裡只有 10 張是專屬的，混在一起根本挑不出來。現在：

- **專屬卡有英雄色的左側色條**（靈夢是紅、紫是紫…），卡池與右側牌表都套用
- 提示框寫明「博麗靈夢 專屬」或「中立卡（所有英雄都能使用）」
- 「歸屬」篩選可以只看專屬或只看中立，按鈕上直接顯示數量
- 牌組張數列改成 **`40 / 40　專屬 22 ・ 中立 18`**，一眼看出這副牌有多少英雄特色

這對**更換英雄**特別重要 —— 有色條的那些就是換英雄時會被移除的卡。

## 6. 實作位置

| 功能 | 檔案 |
|---|---|
| 英雄選擇畫面 | `index.html` 的 `#screen-hero`、`js/ui.js` 的 `openHeroPicker()` / `renderHeroPicker()` / `heroCard()` |
| 英雄橫幅與更換 | `js/ui.js` 的 `renderEditor()` 與 `changeHero()` |
| 新牌組流程 | `js/main.js` 的 `#btn-new-deck` |
| 英雄所屬補充包 | `js/heroes.js` 每位英雄的 `set` 欄位 |
| 卡池篩選 | `js/ui.js` 的 `poolFilter` / `renderPoolFilters()` / `passesFilter()` |
| 英雄技能費用 | `js/engine.js` 的 `heroPowerCost()` / `heroPowerCostType()` / `heroPowerCostLabel()` |

新增英雄時**只要在 `js/heroes.js` 加一筆並寫上 `set`**，選擇畫面、分頁、搜尋、對戰列表都會自動跟上。
