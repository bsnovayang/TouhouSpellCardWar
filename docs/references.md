## 2. 設計方法：從「程度の能力」反推機制

東方每個角色都有官方定義的「○○する程度の能力」。這是**現成的機制說明書** ——
與其先想卡名再湊效果，不如先看能力，機制自然就出來了，而且不會做出角色與效果對不上的卡。

| 角色 | 程度の能力 | 可直接對應的機制 |
|---|---|---|
| 博麗靈夢 | 空を飛ぶ程度の能力 | 飛行、無視守護、無視結界 |
| 霧雨魔理沙 | 魔法を使う程度の能力 | 符卡加成、連鎖發動 |
| 十六夜咲夜 | 時間を操る程度の能力 | 再攻擊、額外回合動作、跳過對手觸發 |
| 紅美鈴 | 気を操る程度の能力 | 守護、回復、格檔減傷 |
| 帕秋莉 | 火水木金土日月を操る程度の能力 | 七元素／多屬性連動 |
| 蕾米莉亞 | **運命**を操る程度の能力 | 指定牌庫頂、強制對手抽到特定牌、鎖定結果 |
| 芙蘭朵露 | ありとあらゆるものを破壊する程度の能力 | 彈幕濺射、破壞結界／場地、無條件消滅 |
| 琪露諾 | 冷気を操る程度の能力 | 凍結（本回合無法攻擊） |
| 露米婭 | 闇を操る程度の能力 | 潛行、使對手無法指定目標 |
| 魂魄妖夢 | 剣術を扱う程度の能力（半人半霊） | 貫通、斬殺、兩個身體（本體＋半靈） |

| 八雲紫 | **境界**を操る程度の能力 | 交換數值、回手、交換血量、跨越牌庫與手牌的界線 |
| 八雲藍 | 式神を使う程度の能力 | 召喚衍生物 |
| 橙 | 人を惑わす程度の能力 | 改變攻擊目標、混亂 |
| 愛麗絲 | 人形を操る程度の能力 | 人偶衍生物、全體操控 |
| 莉格露 | 蟲を操る程度の能力 | 大量小型飛行單位 |
| 米斯蒂婭 | **鳥目**にする程度の能力 | 降低攻擊力、使對手無法看見／指定 |
| 上白澤慧音 | 歴史を食べる／創る程度の能力 | 消除已發生的效果、重置場面、隱藏角色 |
| 因幡帝 | 幸運を分け与える程度の能力 | 給予增益、抽牌運操作 |
| 鈴仙 | 狂気を操る程度の能力 | 使對手行動失效、隨機化目標 |
| 八意永琳 | あらゆる薬を作る程度の能力 | 治療、增益、複製效果 |
| 蓬萊山輝夜 | 永遠と須臾を操る程度の能力 | 延長／跳過回合、費用操作 |
| 藤原妹紅 | 死なない程度の能力 | 復活、不死、死去後回到場上 |
| 蕾迪 | 寒気を操る程度の能力 | 凍結、減速 |

> 之後如果要做第二流派，「指定牌庫頂／鎖定抽牌」是很有辨識度的方向。
> 同理，**慧音的「吃掉歷史」** 可以做成「取消本回合已發生的一個效果」，
> **輝夜的「永遠與須臾」** 可以做成費用與回合操作 —— 這兩個都還沒開發。

## 3. 符卡命名慣例

格式是 **`○符「△△△」`**，前綴兩字表示屬性／流派，引號內是招式名。

- 中階以上有時省略前綴，直接 `○○「△△△」`
- **最終符卡通常只有 `「△△△」`**（沒有前綴），例如「夢想天生」「深弾幕結界」
- 引號用的是日式的 `「」`，不是 `""`

## 8. 使用守則

1. **先有機制再取名**。從 §2 的「程度の能力」推機制，再從 §4 找對得上的符卡名。
   反過來做會產生「名字很帥但效果跟角色無關」的卡。
2. **最終符卡（只有 `「」` 沒前綴的）保留給高費關鍵卡**，不要浪費在 2 費小卡上。
3. **專有名詞寫進卡表前要核對**（§1 的來源），特別是片假名招式名。
4. **二創梗要克制**。梗卡放一兩張當彩蛋沒問題，整副都是梗會讓新玩家看不懂。
5. 新增卡片後跑 `npm run balance`，並更新 [docs/builds.md](builds.md) 的牌表。

## 8. 角色在原作的登場位置（做卡與挑 BGM 時查這裡）

這一節記的是「這個角色是幾面的什麼」，因為它同時決定了**卡片該收在哪一包**
與**該配哪一首曲子**。§1 的三個站都擋掉程式抓取，所以這裡是人工累積的。

| 角色 | 位置 | 對應 BGM |
|---|---|---|
| 莉莉白 | 妖妖夢 **四面道中**（報春的妖精，不是頭目）| 天空の花の都（四面關卡曲）|

> 莉莉白沒有專屬角色曲，用她登場那一面的關卡曲。
> 同類情況（道中角色、無專屬曲）都照這個規則處理。
