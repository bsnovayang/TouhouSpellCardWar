# 各作補充包預計方向

> 依據 [各作英雄參考.md](各作英雄參考.md) 重寫。
> 上一版 [sets.md](sets.md) 假設「一包 2 位英雄」，看到你的參考檔後那個假設不成立 ——
> 你是把**幾乎每位具名角色都當英雄**（紅魔鄉就 11 位），規模完全不同。

---

## 1. 先修正兩個前提

### 1.1 「量不夠」的疑慮可以取消

你的參考檔已經給了 TH06～TH12 共 **7 作、約 50 位英雄**的技能設計。每作 7~11 位，量非常充足。

真正的問題反過來了：**一包 10 位英雄太多**，一次丟出 10 個新流派，平衡調不完、玩家也吃不下。

### 1.2 補充包的節奏建議

| 方案 | 說明 | 風險 |
|---|---|---|
| 一次出滿一作（10 位） | 忠於原作、包裝完整 | 平衡地獄，10 個流派互相影響 |
| **一作拆成 2~3 波** | 先出該作 4~5 位主要角色，之後補完 | 需要「同一作分批」的敘事 |
| **一包一作、但只有主要角色是英雄** | 其餘角色當中立卡 | 冷門角色永遠當不了英雄 |

**建議：一包一作，英雄 4~6 位，其餘角色先當中立卡；日後用「補完包」把剩下的角色升格成英雄。**
這樣每包的新流派數量可控，冷門角色也有未來。

## 2. 同一角色要不要有多版本？

**建議：先不要，但保留機制。**

理由：

- 光是 TH06～TH12 就有 50+ 位角色可以當英雄，**新角色的空間遠比重做舊角色多**。
- 咲夜在妖妖夢仍然是「操縱時間」，機制身分沒變 —— 做第二版只會是同一套的變體，稀釋新鮮感。
- 多版本會讓英雄列表變長、玩家選角時混淆。

**什麼時候才值得做多版本**：該角色在後續作品獲得了**真正不同的機制身分**時。例如：

- 靈夢／魔理沙在**格鬥作**有完全不同的招式體系與立場
- 幽香在 TH04 幻想鄉（BOSS）與 TH09 花映塚（自機）的定位差很多

**做法建議**：多版本英雄**共用同一組職業卡**，只換英雄技能。

```
十六夜咲夜・時符（紅魔鄉）  技能：我方一個角色本回合可再攻擊一次
十六夜咲夜・幻在（格鬥作）  技能：???
              ↑ 兩者都能用 cls:'sakuya' 的全部職業卡
```

成本極低（只多一份 `HEROES` 條目），又創造真正的組牌選擇：**同一套卡、兩種引擎**。
`npm run lint` 會自動擋掉兩個版本技能重複的情況。

## 4. 你的參考檔對引擎的要求

我比對了 [各作英雄參考.md](各作英雄參考.md) 與現有引擎，**落差比想像中大**。以下按「哪一包需要」排序，方便你決定順序。

### 4.1 英雄技能框架（最優先，影響所有包）

現在 `HERO_POWER_COST = 2` 是全域寫死的，但你的參考檔裡：

```
帕秋莉      血量2   ← 用生命當代價，不是靈力
藤原妹紅    靈力0   ← 零費，代價是自傷 2
慧音／鈴仙   靈力3
四季映姬    靈力4
芙蘭朵露    靈力5
```

**需要改成每位英雄各自定義 `cost` 與 `costType`（靈力／血量）。** 這是所有後續包的地基，建議先做。

### 4.2 缺少的關鍵字

目前 14 個，你的參考檔另外用到：

| 關鍵字 | 說明 | 誰需要 | 難度 |
|---|---|---|---|
| **森羅結界**（聖盾）| 擋一次傷害 | 妖妖夢、慧音、寅丸星 | 低 |
| **突襲** | 登場當回合可攻擊角色，但不能打英雄 | 莉格露、射命丸文 | 低 |
| **風怒** | 一回合可攻擊兩次 | 咲夜、白蓮 | 低（引擎已有 `attacksLeft`）|
| **沉默** | 移除角色的所有關鍵字與強化 | 靈夢 | 中 |
| **免疫** | 完全不受傷害 | 妖夢、白蓮 | 低 |
| **劇毒 N** | 每回合結束受 N 點傷害，可疊加 | 梅蒂欣、山女 | 中 |
| **沉睡** | 一回合無法攻擊也不能被指定 | 四季映姬 | 低 |
| **英雄攻擊力** | 英雄自己可以攻擊 | 妹紅、勇儀 | 中（新的戰鬥路徑）|
| **移動位置** | 角色與相鄰者對調位置 | 小町、琪斯美 | 低（已有格子索引）|
| **復活** | 讓死去的角色回到場上 | 燐、永琳 | 中 |

> **建議一包只開放 2~3 個新關鍵字**，不要一次全上。目前 14 個已經接近玩家的記憶上限，
> 雖然有 TAG 提示，但認知負擔仍然存在。

### 4.3 「發現」與「隨機生成」（大工程）

你的參考檔多處用到：

```
小惡魔    隨機從所有牌中生成一張牌，該卡消耗-2
莉莉卡    發現一張「騷靈樂器」法術牌
因幡帝    發現一張隨機的幸運卡牌，其消耗變為 0
輝夜      隨機獲得一張「蓬萊難題」，其消耗變為 5
```

這需要兩套新東西：

1. **隨機生成卡片**：引擎要能憑空造出不在牌組裡的卡（`makeCard` 已可用，但需要「可生成卡池」的定義）
2. **發現（三選一）**：需要**新的 UI 互動模式** —— 暫停遊戲、彈出三張卡讓玩家選。
   這是目前介面完全沒有的流程，也會影響 AI（AI 要能做出選擇）與存檔（選擇進行到一半時的狀態）。

**建議把「發現」延後到有明確需求的那一包再做**，初期先用「隨機獲得一張」（不給選）替代。

### 4.4 卡片族群（部族）

參考檔出現了族群概念：`妖精`、`人偶`、`機械`、`狼人／野獸`、`騷靈樂器`。

現在卡片沒有 `tribe` 欄位。加一個很便宜，但**要先想好族群清單**，之後才不會回頭改幾百張卡。
初步清單建議：`妖精 / 人偶 / 亡靈 / 妖獸 / 式神 / 神明 / 月人 / 鬼 / 人類`。

## 5. 建議的實作順序

| 階段 | 內容 | 為什麼放這裡 |
|---|---|---|
| **0** | `src` / `set` 分離；卡片加 `tribe` 欄位 | 純地基，越晚做越痛 |
| **1** | 英雄技能框架：每位英雄自訂費用與代價類型 | 所有包都依賴它 |
| **2** | 紅魔鄉補完：把參考檔的 11 位英雄實作出來 | 驗證框架，且不需要新關鍵字 |
| **3** | 妖妖夢：**森羅結界** + 該作英雄 | 第一個「一包一系統」的完整範例 |
| **4** | 永夜抄：**人妖組** + 該作英雄 | 補最大的缺口 |
| **5** | 之後依序：花映塚集氣 → 風神錄信仰 → 地靈殿靈擊 → 星蓮船飛碟 | 每包一個新系統 |

> 階段 2 之所以放在關鍵字之前，是因為紅魔鄉的 11 位英雄**只需要現有關鍵字**（吸血、潛行、守護、飛行、冰凍都已經有了）。
> 先用它驗證「英雄技能框架」，再進入需要新關鍵字的妖妖夢，風險最低。
